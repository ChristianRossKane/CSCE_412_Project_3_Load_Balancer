Detailed Description

Header definitions for the CSCE 412 Load Balancer simulation.

"Load balancers are available commercially, but in this project, you will build one that has: - Requests - generates random IP addresses, both in and out, and random times for each request to be processed. - IP in - IP out - Time (integer) - Job Type (Character, p (processing), or s (streaming)) - Webserver(s) - Takes requests from the Load Balancer - Processes the requests - Asks for another - Load Balancer - Queue of requests - Keeps track of time."
